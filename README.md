# ÑandutíProtec — descargas

Como el ñandutí, una red que atrapa a los intrusos. ÑandutíProtec vigila tu PC con Windows y te avisa si
alguien entra, si un programa raro se conecta a internet o si intentan robar tus archivos. Está en español,
con explicaciones claras y arreglos de un clic, y lo puedes manejar desde el celular con Telegram.

## Descargar

Baja el último **NandutiProtec-Setup-X.Y.Z.exe** desde
[Releases](../../releases/latest) y ábrelo con doble clic.

- Windows 10 u 11 de 64 bits.
- Incluye 14 días de prueba del plan Plus.
- Se actualiza solo. Cada actualización va firmada y el programa la comprueba antes de instalarla.
- Modo claro, oscuro o automático (sigue el tema de Windows).

Este repositorio solo contiene los instaladores publicados.
